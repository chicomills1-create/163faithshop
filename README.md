# 163 Faith — Fresh Build · Frontend Scaffold (M1)

Static-first shell per SPEC §1.2. No bundler and no framework: the old face's
11.8 MB embedded catalog chunk is the named anti-pattern, so hub code ships as
separate ES modules, lazy-loaded on first visit, and catalog data will arrive
through the paginated API (§1.7) — never inside a bundle.

## Structure
- `index.html` — the shell: top bar (desktop hub nav + account controls),
  `#hub-root` (the only region replaced on a hub switch), the **persistent
  player** (mounted once, outside the hub root — playback survives switches),
  bottom bar (mobile hub nav).
- `assets/css/shell.css` — design system lifted from the shop page
  (gold `#d4af37` on `#050505`, Georgia serif + system sans).
- `assets/js/shell.js` — hash router, lazy hub loader, player API
  (`window.FaithPlayer`), account-control mounts, and the `?selftest=1`
  proof harness.
- `assets/js/hubs/` — one module per view: `home.js` (the hub selector +
  Meet the Pastor, row MTP) and the seven hubs in nav order
  `watch · listen · read · pray · community · give · shop`.
- `assets/audio/demo-tone.wav` — generated by the build; the scaffold's proof
  track for the persistent player.
- `build.mjs` — generates the tone, syntax-checks every module, copies the
  tree to `dist/`, and writes `proof/build-report.json` with per-entry
  payload measurements.
- `proof/` — build report, rendered screenshots (390px + desktop), the
  self-test report, and `selftest-cdp.mjs` (the real-time CDP driver that
  produces it).

## Run / prove
```bash
node build.mjs                                   # build + payload report
python3 -m http.server 8371 --directory dist     # serve locally
node proof/selftest-cdp.mjs                      # 17-check functional proof
```
Measured at scaffold (2026-11-19): LISTEN entry payload **20,607 bytes**
on disk (budget ≤ 1 MB, SPEC §4); catalog bundle **0 bytes**; self-test
**17/17 PASS** — all hubs render, each module lazy-loads once, the demo tone
plays uninterrupted through all seven hub switches.
